On Windows:
  1. Right-click github-analyzer.tar.gz
  2. Extract with 7-Zip or WinRAR
  3. Right-click the extracted folder → "Open with Code"

On Mac/Linux:
  1. Open Terminal
  2. cd ~/Downloads
  3. tar -xzf github-analyzer.tar.gz
  4. cd code
  5. code .

  npm run dev

Then open: http://localhost:5173
