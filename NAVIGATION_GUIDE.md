# 🔙 Navigation Guide - How to Go Back

## 📍 **All Navigation Options in the App**

---

## **1. From Results Page → Start Over**

### **"Go Back / Analyze Another Profile" Button**

**Location:** Top-left corner of results page

**What it does:**
- Takes you back to the **selection screen**
- Clears all current data
- Lets you start a new analysis

**How to use:**
```
1. Click "Go Back / Analyze Another Profile"
2. You're back at the selection screen
3. Choose: GitHub Only / Portfolio Only / Both
4. Enter new information
5. Analyze again!
```

---

## **2. From Input Form → Selection Screen**

### **"Back to Selection" Button**

**Location:** Top of the input form

**What it does:**
- Takes you back to choose a different analysis type
- Doesn't lose your data until you analyze

**How to use:**
```
1. Click "Back to Selection"
2. You're back at: GitHub Only / Portfolio Only / Both
3. Choose a different option
4. Enter your information
```

## **4. Keyboard Shortcuts**

Currently, no keyboard shortcuts are implemented, but you can use:
- **Browser Back Button (Alt + ←)** - BUT this will reload the page
- **Better:** Use the app's "Go Back" buttons

---

## **5. Examples**

### **Example 1: Change Analysis Type**

```
1. You're on INPUT FORM for "GitHub Only"
2. You realize you want to analyze "Both"
3. Click "Back to Selection"
4. Choose "Both"
5. Enter both GitHub username and Portfolio URL
6. Click "Analyze Now"
```

### **Example 2: Analyze Another Person**

```
1. You just analyzed your friend's GitHub
2. Now you want to analyze yours
3. Click "Go Back / Analyze Another Profile"
4. You're at SELECTION SCREEN
5. Choose analysis type
6. Enter YOUR information
7. Click "Analyze Now"
```

### **Example 3: Fix Mistake in URL**

```
1. You entered wrong portfolio URL
2. Click "Back to Selection"
3. Choose same analysis type
4. Re-enter CORRECT URL
5. Click "Analyze Now"
```

## **6. What Happens When You Go Back?**

### **From Results → Selection:**
- ✅ Clears all analysis data
- ✅ Clears GitHub data
- ✅ Clears Portfolio data
- ✅ Takes you to selection screen
- ✅ Fresh start!

### **From Input Form → Selection:**
- ✅ Clears analysis type selection
- ✅ Takes you to selection screen
- ✅ Doesn't analyze anything
- ✅ You can choose different option

## **8. Tips**

✅ **Use app buttons instead of browser back button**
   - App buttons preserve state better
   - Smoother transitions
   - No page reload

✅ **Go back to change analysis type**
   - If you selected wrong option
   - Click "Back to Selection"

✅ **Start fresh analysis**
   - From results page
   - Click "Go Back / Analyze Another Profile"

❌ **Don't refresh the page**
   - You'll lose all data
   - Have to start from beginning
