# 🚀 AI-Based Portfolio & GitHub Analyzer

An AI-powered web application that helps developers and students evaluate their GitHub profiles and portfolios through interactive analysis, insights, and recommendations.

**🌐 Live Demo:** https://githubportfolioanalyzer.netlify.app/

**💻 GitHub Repository:** https://github.com/mynampati3125/GitHubPortfolioAnalyzer

---

## 🌟 Overview

The AI-Based Portfolio & GitHub Analyzer is designed to assess coding activity, repository quality, technology stack diversity, and portfolio presentation. The platform provides a user-friendly dashboard that helps users identify strengths, weaknesses, and opportunities for improvement.

This project was designed in Figma, converted into a React application using Figma Make, enhanced in VS Code, and deployed on Netlify.

---

## ✨ Features

* GitHub Profile Analysis
* Portfolio Quality Assessment
* Coding Consistency Evaluation
* Tech Stack Diversity Analysis
* Interactive Dashboard
* Modern Responsive User Interface
* Multiple Analysis Modes:

  * GitHub Only
  * Portfolio Only
  * Combined Analysis

## 🔄 Workflow

1. Select an analysis type.
2. Enter GitHub username or portfolio details.
3. Process and analyze the provided information.
4. Generate scores and insights.
5. Display results through an interactive dashboard.
6. Provide recommendations for profile improvement.

## ⚙️ Local Setup

Clone the repository:

```bash
git clone https://github.com/mynampati3125/GitHubPortfolioAnalyzer.git
```

Navigate to the project directory:

```bash
cd GitHubPortfolioAnalyzer
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:5173
```
